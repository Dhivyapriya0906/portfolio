# Dhivya.dev Portfolio

This portfolio is a static HTML, CSS, and browser-JavaScript site. The deployable copy is in `public/` and has no runtime or build dependencies.

## Deploy to Vercel

- Root Directory: `.` (the repository root)
- Framework Preset: `Other`
- Build Command: leave blank
- Output Directory: `public` (also configured in `vercel.json`)
- Install Command: leave blank

The site and its images, recognition photos, and resume are served directly from `public/`.
